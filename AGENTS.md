# Project continuity

Read `PROJECT_CONTEXT.md` before changing this project. It records the user's accepted design direction, current behavior, architecture, and verification history. Preserve these decisions unless the user requests a change. Update it after significant changes so later sessions can continue from the actual implementation.

Do not put passwords, password hashes, session tokens, or other secrets in project notes or tool output. Administrator credentials belong only in the existing ignored local credential/environment files.
